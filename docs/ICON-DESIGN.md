# TotalMix-OSC-Remote アイコン・液晶表示デザイン

Stream Deck のキー LCD / Stream Deck + のタッチストリップに表示するアイコンとレイアウトのデザイン仕様。ドラフト SVG は [assets/icons/](../assets/icons/) に、モックアップは [assets/mockups/](../assets/mockups/) に置く。

## デザイン言語

- **背景**: ダークグレー基調(#26262a → #121214 の縦グラデーション)。Stream Deck 本体の黒ベゼルと馴染ませる。
- **カラーロール**(RME/TotalMix FX の配色に対応):
  - **レベル/フェーダー = グリーン #21D24C**(レベルメーターのグリーン)。ダイヤルノブの値アーク、タッチストリップの dB 値・バーに使用
  - **Mute 点灯 = ブルー #2FB1E3**(M ボタンの点灯色)
  - **Dim 点灯 = オレンジ #F5A623**(減衰・注意喚起。フェーダーを操作中の状態であることを示す)
  - 当初は全アクセント=オレンジ、Mute=赤だったが、RME の基調カラーに合わせて上記へ変更
- **グリフ**: ホワイト #E8E8EC / グレー #8A8A92 の2階調。線幅は 144px キャンバスで 6–8px(視認距離 50cm・実寸 15mm 角の LCD で潰れない太さ)。
- **状態表現**: OFF = 無彩色グリフ+ラベル、ON = アクセント色グリフ+同色の枠線+背景に同系の暗色ティント。点灯/消灯が一目で分かるようにする。

### 運用

- マスターは SVG で管理し、ビルド時に @1x/@2x PNG へ書き出す(`name.png` + `name@2x.png`、manifest には拡張子なしで記載)。キー画像は SVG 直接参照も可(SDK 推奨形式)。
- プラグインアイコンのみ PNG 必須(256×256/512×512)。

## タッチストリップ(ダイヤル)レイアウト

Stream Deck + のダイヤル1本あたりのタッチストリップ領域(200×100 px)に表示する内容:

```
┌────────────────────────────────┐
│ ◔(ノブアイコン)  Main          │  ← タイトル: 対象チャンネル名(設定で変更可)
│                  -12.0 dB      │  ← 値: TotalMix からのフィードバック文字列(*Val)
│         ▐███████░░░░▌          │  ← バー: フェーダー位置 0–100%
└────────────────────────────────┘
```

- **タイトル**: ユーザーが Property Inspector で付けた名前(既定は「Main」等のターゲット名)。
- **値表示**: TotalMix が返す dB 文字列(例 `-12.0 dB`)をそのまま表示。フィードバック未受信時はローカル計算の % 表示にフォールバック。
- **バー**: 送信中の Float 値(0.0–1.0)を 0–100 にスケールして表示。
- Mute 中はバーとdB値を赤 (#E03C3C) に切り替え、タッチストリップ上でも消音が分かるようにする。

組み込みレイアウト(値+バーの `$B1` 系)で足りる場合は組み込みを使い、dB 文字列とバー色変更を両立させたい場合はカスタムレイアウト JSON を定義する(実装計画参照)。

## キー LCD 表示

- **Mute キー**: manifest の 2 States(off/on)で切り替え。ON 時は青枠+青グリフ(TotalMix の M 点灯色)。タイトル欄はユーザー設定(チャンネル名)を下部に白文字表示できるよう、グリフを上寄せ配置(下 1/4 をラベル帯として空ける)。
- **Fader Dim キー**: 同様に 2 States。ON 時はオレンジ。LCD 上のグリフ内表記は「DIM」。Dim 量(例 `-20dB`)を Property Inspector で設定した場合、`setTitle` で数値をラベル表示することも検討。

## 参考(スクリーンショットからの学び)

既存 OSC Remote プラグイン+Volume Controller の画面から:

- タッチストリップは「タイトル+数値+横バー」の構成が視認性が高い(既存 Volume Controller は `Main / 13% / バー` 構成)。本プラグインでは % ではなく **dB 表記**を第一級にする(TotalMix ユーザーの思考単位に合わせる)。
- キーアイコンは白グリフ+黒背景が Stream Deck の他アイコンと馴染む。状態色(赤/オレンジ)は ON 状態のみに使い、通常時は無彩色にして盤面がうるさくならないようにする。
